# 忍者收集与修炼伙伴设计

用户已批准：在当前仓库的 dev 分支实现 25 人图鉴、固定修炼里程碑和可选伙伴。

- 初始拥有鸣人；首次豪火球、千鸟、通灵分别解锁佐助、卡卡西、波风水门。
- 其余人物按图片编号依次使用累计真实施术 3、5、8、12、16、20、25、30、36、42、50、60、70、80、90、100、115、130、150、175、200 次解锁。
- 全部解锁状态由现有 Mastery 推导；原进度键及结构不变。伙伴 ID 单独保存到 naruto-spiritism.companion.v1。
- 加载历史记录后恢复伙伴；无效或未解锁 ID 回退到鸣人。存储失败保留会话内状态并提示。
- 展览馆增加 /gallery?tab=ninjas；未解锁显示剪影、文字条件与进度。已解锁可设为伙伴。
- 修炼场侧栏展示伙伴；真实施术演出结束后合并展示新增解锁，支持关闭与图鉴入口。预览和单印练习不奖励，历史进度不弹奖励。
- 原 PNG 不修改，不自动抠图；人物使用浅色卡片，等比像素展示。身份不确定者暂用忍者档案编号。
- 适配 375px / 1440px，按钮至少 44px，键盘可操作，动画尊重 reduced-motion。
- 不增加战斗属性、抽卡、兑换、账号或服务器。不自动提交、推送、合并。

验收：领域与存储边界、图鉴导航与选择持久化、真实模型回放奖励、响应式和键盘，以及六项项目检查。
